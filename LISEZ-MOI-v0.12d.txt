ATLAS KARST ASCII v0.12d — POINTS NORMALISÉS & INDEX SPATIAL

Cette version repart directement de la v0.12b. Elle n'inclut aucun script GitHub,
aucune Action et aucun fichier de pré-synchronisation.

Nouveautés internes :
- format commun pour les points d'intérêt : identifiant, catégorie, sous-type,
  titre, source, coordonnées, priorité et donnée brute d'origine ;
- index spatial léger pour les points d'intérêt, OSM et le cadastre ;
- les rendus interrogent uniquement les objets présents dans l'emprise visible ;
- les fiches, sons et effets utilisent désormais la catégorie normalisée du POI ;
- la rubrique Diagnostic affiche le nombre de POI indexés et l'état de l'index.

Les données brutes et les formats d'import/export restent compatibles avec la
v0.12b. L'index est reconstruit uniquement lorsqu'une couche de données change.

Mode diagnostic : ajouter ?debug à l'URL ou utiliser Ctrl + Maj + D.
